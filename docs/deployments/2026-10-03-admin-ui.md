## Rollback

Run as ubuntu in the AWS terminal if rollback is needed. This briefly interrupts the application. Confirm the current release paths before running.

```bash
export PATH="/home/ubuntu/.nvm/versions/node/v22.23.2/bin:$PATH"
test -d /var/www/meditation-deploy/releases/legacy-before-admin-20261003/.next
ln -s /var/www/meditation-deploy/releases/legacy-before-admin-20261003 /var/www/meditation-deploy/rollback-current
pm2 stop meditation
mv -Tf /var/www/meditation-deploy/rollback-current /var/www/meditation-deploy/current
pm2 restart meditation
curl -I https://admin.anchorintopresence.net/admin/login
```

Retain the prior release: the new release links to its upload directories.
